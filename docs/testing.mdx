```bash
pytest tests/ -v
```

Every test runs with no Alpaca keys, no Bright Data token, no Anthropic key,
and no network access. `tests/conftest.py` provides `FakeBroker` and
`FakeMarketData`; the news and LLM tests use `httpx.MockTransport` and a
fake Anthropic client respectively. CI runs the same suite with the process
environment stripped, as an extra check that nothing quietly depends on a
real credential being present.

## yfinance is offline by default, not by exception

An autouse fixture in `conftest.py` replaces the shared context provider
singleton with one that returns an empty payload and a stated gap:

```python
@pytest.fixture(autouse=True)
def _offline_market_context(monkeypatch):
    class OfflineProvider:
        def fetch(self, ticker: str) -> ctx.RawMarketData:
            return ctx.RawMarketData(gaps=["market context disabled in tests"])

    monkeypatch.setattr(ctx, "_provider", OfflineProvider())
```

Two things fall out of that. No test can reach yfinance even by accident —
and the shape it gets instead is exactly the shape a real outage produces, so
the **degraded path is the default in every test**, not a special case
someone has to remember to write. A test that wants real snapshots injects
its own provider. A sibling fixture redirects both log files to `tmp_path`,
so the suite never writes into the repository's `logs/` directory.

## A test suite is only as good as its negative cases

A recurring pattern in this codebase: when a test claims a guardrail holds,
there's a companion test proving the *opposite* input trips it. For example,
`test_risk_engine.py` doesn't just assert the 5% cap is respected on a
compliant input — it asserts that an input designed to overflow the cap
after rounding raises `RiskViolation`.

The same discipline was applied manually to the fallback logic while
building it: the switch-point-reading logic in `orchestrator/llm.py` was
temporarily reverted to prove `test_answer_is_taken_from_the_model_that_did_not_decline`
actually fails without it, before restoring the fix.

```bash
pytest tests/ --cov=app --cov=orchestrator --cov=config
```

<Note>
  Coverage isn't wired into CI — the guardrail invariants job (see
  [Continuous Integration](/continuous-integration)) checks structural
  properties that line coverage can't, like "does anything outside
  `broker_client.py` import the Alpaca SDK."
</Note>
